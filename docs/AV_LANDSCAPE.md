# Как устроены VirusTotal, Касперский, Защитник Windows и другие — и что из этого есть в Sentinel

Справка для разработки: принципы работы известных антивирусов и сервисов, сравнение с Sentinel и план развития.
В конце — учебный план по кибербезопасности для того, кто пишет антивирус.

## 1. VirusTotal

VirusTotal — это не антивирус, а агрегатор: он прогоняет файл через десятки чужих движков и собирает про него всё, что известно.

- **Сначала хеш.** Поиск по SHA-256 (или MD5/SHA-1) ничего не загружает: если файл уже видели, сразу показываются
  результаты движков, дата первого появления, имена файла, распространённость. Загружать стоит только то, что не жалко
  показать: загруженные файлы доступны платным клиентам сервиса. Личные документы туда загружать нельзя.
- **~70 движков.** Каждый движок работает в конфигурации для VirusTotal: часто без облака и с агрессивной эвристикой.
  Поэтому «3 из 70» — не вердикт, а повод разобраться; у десктопного продукта того же вендора ответ может отличаться.
- **Песочницы.** Файл запускается в нескольких изолированных средах. В отчёт попадают созданные процессы, файлы и ключи
  реестра, сетевые обращения, сопоставление с техниками MITRE ATT&CK.
- **Сообщество.** Правила YARA (Livehunt/Retrohunt), Sigma и IDS, голоса и комментарии исследователей.
- **Связи.** Граф «файл → домены, IP-адреса, URL → другие файлы» и «родитель → сброшенные файлы» позволяет найти всю
  инфраструктуру семейства по одному образцу.
- **Похожие файлы.** Нечёткие хеши (ssdeep, TLSH, vhash), imphash (хеш таблицы импорта) и icon hash находят варианты одного
  и того же вредоноса с разными SHA-256.

## 2. Касперский

Слоёная защита: каждый слой ловит то, что пропустил предыдущий.

- **Сигнатуры и базы.** Обновляются несколько раз в час; кроме точных хешей — «расширенные» записи, ловящие семейство.
- **Эвристический анализатор.** Эмулирует код в виртуальной среде и смотрит, что он делает. Уровень настраивается:
  поверхностный / средний / глубокий — компромисс между скоростью и обнаружением.
- **Kaspersky Security Network (KSN).** Облако репутации: файлы и URL, которые уже видели миллионы установок, получают
  вердикт за доли секунды; известные чистые файлы не проверяются повторно.
- **Мониторинг активности (System Watcher).** Поведенческий анализ процессов и **откат действий** вредоноса (восстановление
  зашифрованных/удалённых файлов, ключей реестра).
- **Защита от эксплойтов, AMSI.** Скрипты PowerShell/VBScript проверяются через AMSI в памяти до выполнения.
- **Самозащита.** Никто, кроме самого антивируса, не может изменить его процессы, файлы, ключи реестра и службы; настройки
  можно закрыть паролем.
- **Режимы проверки.** Быстрая (память, автозагрузка, системные области), полная, выборочная, проверка съёмных дисков,
  **проверка в режиме простоя** (когда пользователь не работает), фоновая проверка.
- **Оптимизация.** iChecker/iSwift — пропуск неизменённых с прошлой проверки файлов по базе контрольных сумм и данным NTFS;
  **«уступать ресурсы другим приложениям»**; отложенный запуск задач при работе от батареи и в полноэкранных играх.
- **Режим доверенных программ.** Запуск разрешён только известным доверенным приложениям (по умолчанию — запрет).
- **KVRT.** Бесплатная разовая утилита: только проверка и лечение, без постоянной защиты.

## 3. Защитник Windows (Microsoft Defender)

- **Защита в реальном времени** через драйвер-минифильтр: файл проверяется при открытии/записи (on-access).
- **Облачная защита и блокировка при первом появлении** (MAPS): неизвестный файл задерживается на ~10 с до вердикта облака.
- **Поведенческий мониторинг, AMSI, правила сокращения поверхности атак (ASR)** — например, запрет Office создавать
  дочерние процессы.
- **Контролируемый доступ к папкам** (защита от шифровальщиков), **защита сети**, **защита от подделки** (Tamper Protection).
- **ELAM-драйвер и PPL.** Антивирус стартует до сторонних драйверов и защищён ядром; это доступно только вендорам,
  подписанным Microsoft.
- **Автономная проверка** из среды восстановления (WinRE) — против руткитов, которые прячутся в работающей системе.
- **Слабое место — исключения.** Их часто добавляет сам вредонос (как CAAService и techias), поэтому Sentinel их проверяет.

## 4. Другие

- **ESET:** LiveGrid (облако), Advanced Memory Scanner (проверка памяти процесса после распаковки), HIPS, сканер UEFI,
  DNA-детекты (описание поведения, а не байтов).
- **Bitdefender:** Process Inspector — непрерывная оценка баллами поведения каждого процесса (похоже на скоринг Sentinel).
- **Malwarebytes:** анти-эксплойт и анти-шифровальщик поверх основного антивируса.

## 5. Сравнение с Sentinel

| Технология | Где у других | Sentinel | Что сделано / план |
|---|---|---|---|
| Сигнатуры и хеш-базы | у всех | есть | YARA-подобные и JSON-правила, IOC семейств; 1.3.9 — SHA-256, SHA-1 и MD5 из ESET, signature-base, отчётов Talos/Unit 42/Sophos, VirusShare, MalwareBazaar (по ключу) и фидов abuse.ch |
| Эвристика / скоринг | Касперский, Bitdefender | есть | `ThreatScoringEngine` 0–100 + `FalsePositiveGuard`; 1.3.8 — точнее признак патчинга ETW |
| Облачная репутация | KSN, MAPS, LiveGrid | есть | VirusTotal и Kaspersky OpenTIP по ключам пользователя; 1.3.9 — «белое облако» CIRCL hashlookup/NSRL (по согласию); только хеш, без загрузки файлов |
| Проверка памяти | ESET AMS | есть | `MemoryIntegrityScanner`; 1.3.8 — выборочно в фоне (не каждая вкладка браузера) |
| Поведение + откат | System Watcher | частично | корреляция, анти-шифровальщик, детектор «пряток» от Диспетчера задач, плейбук семейств с манифестом отката |
| Пропуск неизменённых файлов | iChecker/iSwift | есть | кэш вердиктов проверки; 1.3.8 — кэш анализа в службе (меньше нагрузки и шума вентиляторов) |
| Уступать ресурсы | Касперский | есть с 1.3.8 | рабочие процессы проверки с пониженным приоритетом |
| Самозащита | все | есть | DACL процесса службы и каталога данных; 1.3.8 — канал управления: ослабляющие команды только из окна Sentinel или от администратора |
| Аудит исключений и политик Защитника | — | есть | исключения, политики отключения, события 5007 |
| On-access минифильтр | Защитник, все | нет | драйвер пока только телеметрия; план — минифильтр с проверкой при записи/запуске |
| AMSI-провайдер | Касперский, Защитник | нет | план — нативная COM-DLL провайдера, проверка скриптов PowerShell до выполнения |
| ELAM / PPL | Защитник, крупные вендоры | недоступно | нужна подпись Microsoft для антивирусных вендоров |
| Проверка в простое, режим ноутбука/игр | Касперский | частично | 1.3.9 — режим ноутбука: от батареи плановый аудит автозагрузки реже (скорость проверки не снижается); план — режим игр и проверка в простое |
| Нечёткие хеши (imphash, TLSH) | VirusTotal | нет | план — находить варианты семейств с другим SHA-256 |
| Пароль на настройки | Касперский | нет | план |

## 6. Учебный план по кибербезопасности (для разработчика антивируса)

1. **Устройство Windows.** Процессы и потоки, маркеры доступа и уровни целостности, DACL, службы и SCM, реестр
   автозагрузки, драйверы и минифильтры. Книга «Windows Internals» (Йосифович, Руссинович и др.).
2. **Формат PE.** Заголовки, секции, импорт/экспорт, ресурсы, подписи Authenticode и каталоги `.cat` — основа любого
   статического анализа.
3. **MITRE ATT&CK.** Язык описания техник. Семейства из `docs/THREAT_FAMILIES.md` в его терминах:
   T1547.001 (Run-ключи), T1053.005 (задачи Планировщика), T1562.001 (исключения и отключение защиты), T1036.005
   (маскировка под системные имена), T1059.001 + T1105 (`irm … | iex`), T1496 (майнинг за чужой счёт).
4. **Инструменты наблюдения.** Sysinternals: Process Explorer, Autoruns, Procmon, Sigcheck; Sysmon и ETW;
   журнал Защитника. Почти каждый детектор Sentinel начинался с того, что так видно руками.
5. **Анализ вредоносов.** Сначала статический (строки, импорт, YARA), затем динамический — **только** в изолированной
   виртуальной машине без общей сети и общих папок (FLARE-VM, REMnux). Образцы — с MalwareBazaar в архиве с паролем;
   на основном компьютере их не открывают.
6. **Инженерия детектов.** YARA и Sigma, измерение ложных срабатываний на чистых системах, принцип «один признак —
   средняя уверенность, связка — высокая», который используется в Sentinel.
7. **Защита самого антивируса.** Модель угроз: вредонос работает от имени пользователя и пытается выключить защиту,
   внести себя в исключения, подменить вердикт. Каждый канал управления и каждый файл настроек — точка атаки.
